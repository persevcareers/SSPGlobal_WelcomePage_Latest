## 4️⃣ Key Gaps / Risks

### 🔴 Critical Bug — TC003: Navigation Links Open External Pages Instead of Scrolling

**Affected Element:** `<a href="https://www.ssptechedu.com/" target="_blank">Training</a>` in the header nav.

**Expected Behavior:** Clicking "Training" in the header should smoothly scroll the user to a Training-related section on the homepage.

**Actual Behavior:** The link opens the external SSP Tech Edu website in a new tab, abandoning the user from the SSP Global homepage.

**Recommended Fix:** Either:
1. Change the `href` to an anchor (`href="#s-split"`) pointing to the relevant in-page section, **or**
2. Keep the external link but add a separate "Explore Training ↗" CTA and make the nav link scroll to the S-Split section.
